# @svbk/api

NestJS backend for the SVBK multi-tenant school fee management system.

## Scripts

```bash
pnpm dev        # nest start --watch
pnpm build      # nest build
pnpm start      # nest start (prod)
pnpm test       # jest
pnpm lint       # eslint --fix
pnpm typecheck  # tsc --noEmit
```

Run from the monorepo root with `pnpm --filter @svbk/api <script>` or
from this folder directly.
